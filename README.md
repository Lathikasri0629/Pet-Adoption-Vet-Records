# Pet Adoption and Veterinary Records Management System

A Java and MySQL project (OOPs and DBMS) for managing pets, adopters, adoptions and vaccinations in an animal shelter.

## Features
- Add, view, update and delete pets (CRUD)
- Register adopters and adopt pets (transaction with rollback)
- Custom exception for duplicate adoption
- Vaccination records and a list of vaccinations due in 30 days

## Tech stack
Java 21, Eclipse, MySQL 8.0, JDBC (Connector/J)

## OOP concepts
Abstraction, inheritance, polymorphism, encapsulation, exception handling

## How to run
1. Create the `petcare` database and its tables in MySQL Workbench.
2. Open `DBConnection.java` and set your MySQL password.
3. Add the MySQL Connector/J jar to the project build path.
4. Run `Main.java` and use the console menu.
